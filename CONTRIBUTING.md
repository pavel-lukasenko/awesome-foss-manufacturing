# Contributing to Awesome FOSS for Decentralised Manufacturing

Thank you for your interest in contributing! This list aims to be the most comprehensive reference for FOSS tools that form the structural backbone of decentralised digital fabrication ecosystems.

## How to Contribute

### Adding a New Tool or Resource

1. **Fork** this repository
2. **Edit** `README.md` and add your entry to the appropriate section
3. **Submit** a pull request with a clear description of what you added and why

### Entry Format

Please follow the existing table format:

```markdown
| [Project Name](https://github.com/org/repo) | Brief description of what it does and why it matters for decentralised manufacturing. | License-ID |
```

**Guidelines for entries:**

- The project should be **Free and Open Source Software** or **Open Hardware** (exceptions for proprietary-but-free tools are noted explicitly and should be rare)
- Include the **canonical repository link** (GitHub/GitLab preferred) or project homepage
- Keep descriptions to **one or two sentences** — focus on what the tool does and its role in the fabrication ecosystem
- Specify the **SPDX license identifier** where possible
- Place entries **alphabetically** within their section, or by relevance/maturity if a clear ordering exists

### Suggesting a New Section

If you think the list is missing an entire category, open an **issue** first to discuss it before submitting a PR.

### Reporting Broken Links or Outdated Information

Please open an **issue** with:
- The project name and current link
- What changed (project archived, renamed, moved, license changed, etc.)
- Suggested replacement if applicable

## Quality Standards

We prioritise tools that:

- Have **active development** or a **stable, maintained release**
- Are **actually used** in real fabrication workflows (not just proof-of-concept)
- Have **documentation** sufficient for a new user to get started
- Are **genuinely open** — not open-core with essential features locked behind a paywall

## Code of Conduct

Be respectful and constructive. This is a community resource. Disagreements about tool inclusion should focus on technical merit and relevance to the decentralised manufacturing ecosystem, not on personal preferences or commercial interests.

## Questions?

Open an issue for any questions about the list scope or contribution process.
